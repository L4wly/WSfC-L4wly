## Main Topic of the Assignment:
<p>You have 10 employees in your shop, each earning a different hourly wage and working a different number of hours. Write an algorithm to calculate the total monthly wage for all workers. Include logic (e.g., switch-case) to handle different working hour categories. Finally, implement and run the code.</p>

## What can this program do?
This program have 4 different function;
- Enter `0` for the `Demo` function. This is a basic solution for the assignment topic.
- Enter `1` to calculate the `Workers' Monthly Salary`. This function randomly selects the workers' level (Part-Time, Junior, Intermediate, Senior), working hours, and hourly wages.
- Enter `2` to calculate the `Company's Monthly Expenses`. This function operates similarly to function `1`, but it also includes `Default Other Expenses (bills, taxes, rent, etc.)` in the calculation.
- Enter `3` to calculate the `Advanced Calculating`. This function operates similarly to function `2`, but allows you to modify the `Other Expenses` amount.
